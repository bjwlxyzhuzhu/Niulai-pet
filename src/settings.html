DeepSeek 对话

填入 API key 之后，右键菜单里的「聊聊」才能用。 key 会用 Windows 账户密钥加密后存在本机，程序里没有任何一处能把它读回界面。 注意：你在聊天窗口里发的内容会送到 DeepSeek 的服务器。 天气播报和日程提醒不走这条路，你的日程不会被发出去。

牛来的声音

用微软 Edge「朗读」背后的免费接口，不需要注册也不要 key。 只朗读聊天窗口里的回复——早晚播报不读，因为那里面有你的日程。 这是个非公开接口，目前微软已收紧，多半连不上；连不上时自动改用系统自带的中文语音，系统也没有就只显示文字。

天气

用 Open-Meteo，免费、不需要注册。搜到城市后点一下选中，只有经纬度会被发出去。

日程

日程直接读你本机 Cclock（桌面时钟悬浮窗）里的待办，只读不写。 在 Cclock 里加的待办，只要带日期且没打勾，牛来就会算进提醒。

播报时间

早上报今天，傍晚报明天。到点时牛来会用气泡说出来。
